Privacy Policy

Last updated: November 17, 2026

"Hindsight Atlas Uploader" (the "App") is a personal tool that uploads videos to the owner's own YouTube channel through the YouTube Data API. This policy explains what data the App accesses and how it is used.

Data the App accesses

When the owner signs in with Google, the App requests permission to upload videos to the owner's YouTube channel. The App uses this access only to upload videos and their thumbnails to that channel. It does not read, edit or delete anything else on the channel.

How data is used

Google user data is used only to provide the App's single function: uploading videos to the owner's YouTube channel. It is not used for advertising, is not sold, and is not shared with third parties.

Storage

The App stores the OAuth authorization token locally on the owner's own computer or server so it can keep working without asking to sign in every time. The App does not collect, store, or transmit any other personal data, and it does not operate a public database of user information.

Google API Services User Data Policy

The App's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

You can revoke the App's access at any time at myaccount.google.com/permissions.
